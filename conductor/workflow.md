# Development Workflow

## Principles

1.  **User-Controlled Commits:** The agent will **NOT** perform automated commits. The user is responsible for managing version control.
2.  **No Test Coverage Mandate:** While tests are encouraged for critical logic, there is no strict code coverage percentage requirement.
3.  **Task-Based Execution:** Development is broken down into small, manageable tasks.
4.  **No Git Notes:** Task summaries are not stored in Git Notes.

## Phase Completion Verification and Checkpointing Protocol

At the end of each phase, the following steps must be taken:

1.  **Verification:** Ensure all tasks in the phase are marked as completed.
2.  **Manual Checkpoint:** The user should review the changes and commit them if satisfied.
3.  **Next Phase:** Proceed to the next phase only after user confirmation.
